# ARGUS Typography — Phase 7 Gate 3

**Status:** Locked.

## Concepts evaluated
1. **Instrument + Source Serif** — editorial (rejected: broadsheet risk)
2. **Geist + Geist Mono** — Vercel-like (acceptable but generic)
3. **Söhne-like + IBM Plex Mono** — (licensing friction)
4. **“Precision Pair” — Manrope + IBM Plex Sans + IBM Plex Mono** — **ADOPTED**
5. **Fraunces + Inter** — (rejected: Inter default + display mismatch)
6. **Space Grotesk + DM Sans** — (rejected: startup-generic)

## Locked type system

| Role | Font | Weight | Notes |
|------|------|--------|-------|
| Brand / H1 | Manrope | 700 | Expressive, modern, not Inter |
| Headings H2–H4 | Manrope | 600 | |
| Body | IBM Plex Sans | 400/500 | Excellent UI density |
| Numbers / KPIs | IBM Plex Mono | 500 | Tabular figures for risk scores |
| Tables | IBM Plex Sans | 400 | 13–14px |
| Code / citations IDs | IBM Plex Mono | 400 | |
| Chat messages | IBM Plex Sans | 400 | 15–16px |

## Scale
- Display: 40/48 (landing brand)
- H1: 32/40
- H2: 24/32
- H3: 18/28
- Body: 15/24
- Small: 13/20
- Micro: 11/16 (badges, meta)

## Reasoning
Manrope carries brand without serif nostalgia. IBM Plex family is engineered for dense operational UIs and pairs cleanly with mono for SHAP values and case IDs.
