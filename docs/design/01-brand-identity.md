# ARGUS Brand Identity — Phase 7 Gate 1

**Status:** Locked for implementation (autonomous gate — recommendation adopted).

## Concepts evaluated

### Concept A — “Command Precision”
Ink navy + signal amber. Feels like a mission console: calm authority, high legibility, critic corrections in amber. Closest to Mercury / Linear operational tools.
- **Advantages:** Trustworthy for police buyers; critic moment reads clearly; maps well to dark/light.
- **Disadvantages:** Can feel austere if over-used.
- **Best for:** B2B GovTech ops products.
- **Verdict:** **RECOMMENDED — ADOPTED**

### Concept B — “Civic Trust”
Off-white paper surfaces, forest green accents, soft serif wordmark.
- **Advantages:** Warm, institutional.
- **Disadvantages:** Risks cream/terracotta AI-default look; weaker “command” signal.
- **Best for:** Public civic portals, not investigator tools.

### Concept C — “Night Ops”
Near-black UI, electric cyan accents, heavy glow.
- **Advantages:** Dramatic demo presence.
- **Disadvantages:** Glow/purple-cyan cliché; fatigue for daily use; a11y harder.
- **Best for:** Pure demo stage, not SaaS daily driver.

### Concept D — “Clean Ledger”
Stripe-like white + blue, generous whitespace, soft cards.
- **Advantages:** Instant SaaS familiarity; great for billing/landing.
- **Disadvantages:** Weak crime-intel differentiation; easy to look generic.
- **Best for:** Fintech billing surfaces.

### Concept E — “Field Notebook”
Kraft textures, stamp marks, monospace everywhere.
- **Advantages:** Memorable.
- **Disadvantages:** Novelty over function; poor density for tables/maps.
- **Best for:** Marketing microsites only.

### Concept F — “Glass Stack”
Translucent panels, blurred maps behind chrome.
- **Advantages:** Premium screenshots.
- **Disadvantages:** Performance + readability cost on heatmaps.
- **Best for:** Landing hero only.

## Locked brand

| Attribute | Decision |
|-----------|----------|
| Name | ARGUS |
| Tagline | Ask. See. Predict. One audited truth. |
| Personality | Precise, calm, accountable, unsentimental |
